01

Free installation · no computer

Free, No PC

Install the IPA on your iPhone using Tale DNS and Ksign.

Guide by: xyzAtanas

Requirements

  • Brain
  • Tale Stars IPA
!

🔴 DNS REQUIRED

If it says “DNS REQUIRED” above, this step is required before continuing.

  1. Download Tale DNS.
  2. Go to Settings → General → VPN & Device Management → Tale DNS, then press Install.
  3. Go back to VPN & Device Management → DNS and select Tale DNS Install Only.
01

Download Ksign

  1. Go to khoindvn.io.vn.
  2. Scroll down and press Ksign.
  3. Press Install on every Ksign option until one works.
  4. Press Install if there is a pop-up. If there are ads, close them.
  5. Go to your home screen and press Ksign. It should ask you to trust the certificate.
  6. Go to Settings → VPN & Device Management → Certificate name → Trust.
  7. You will be prompted to trust the certificate.
  8. Once you are back at the home screen, change the DNS to Anti-Revoke if you have it.
02

Using Ksign

  1. Open Ksign.
  2. Go to Library.
  3. Press the +, then Import from Files, and select your IPA.
  4. Once imported, change the DNS setting to Install Only if you have that option.
  5. Press Tale Stars → Sign & Install → Identifier and change it to com.tale.stars.
  6. Go back and press Start Signing.
  7. Wait until it says Installing.
  8. Press Install on the prompt.
  9. Wait until it installs.
03

Enabling Anti-Revoke DNS

Optional · recommended
  1. If you have not already, install Tale DNS.
  2. Go to Settings → General → VPN & Device Management → DNS and select Tale DNS Anti-Revoke.
02

Free installation · computer required

Free, PC

Use Sideloadly on your computer, then finish setup on your iPhone.

Guide by: vsayc

Requirements

Download the necessary files to your computer:

  • Sideloadly
  • iTunes
  • Tale Stars IPA
01

Computer setup & installation

  1. Open Sideloadly on your computer.
  2. Connect your iPhone via USB.
  3. Select the downloaded .ipa file.
  4. Enter your Apple ID and sign in.
  5. Click Start to begin.
02

Enable Developer Mode

On your iPhone, enable Developer Mode before launching:

  1. Open Settings.
  2. Tap Privacy & Security.
  3. Scroll down and tap Developer Mode.
  4. Toggle it on and restart.
03

Trust the profile

  1. After the restart, open Settings.
  2. Go to General → VPN & Device Management.
  3. Select the profile associated with your Apple ID.
  4. Tap Trust, then confirm.

The app will now launch.

03

Paid installation · no computer

Paid, No PC

Use a paid certificate service, then install the signer app and Tale Stars on your iPhone.

Guide by: xyzAtanas

i

Certificate prices and availability can change. Check the main muacert website for current details before topping up.

  1. Open muacert.com in your browser. Create an account or log in if you already have one.
  2. Go to the top-up page and add funds. Check the main website for current certificate prices.
  3. Go to Add Device and press Get UDID. Download the profile, then open Settings → Profile Downloaded and install it. This will redirect you back to the page.
  4. Choose your currency (VND or USD), select the certificate option you want, then press Add Device.
  5. You will be redirected to your device’s page. Press Install signer app, select Ksign, and press Download Now. Tap Install on the pop-up.
  6. Open Settings → Privacy & Security → Developer Mode and toggle it on. Follow the instructions when your phone restarts. Developer Mode is required for Ksign to work properly.
  7. Open Ksign and check that your certificate is imported in Settings. Go to Library, press the + button, and select the Tale Stars IPA file. You can download the IPA from t.me/talefiles/27.
  8. Once the IPA is imported, press Tale Stars → Sign & Install → Properties and enable Game Mode for better performance.
  9. Wait until you see “*backloop.dev wants to install Tale Stars”, then press Install. Wait until it says completed.
  10. Done! You can now open Tale Stars from your home screen.
